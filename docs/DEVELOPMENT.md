# Разработка Auris на Windows

Репозиторий: https://github.com/bglglzd/auris.
Локальная рабочая папка: `C:\Users\bglgl\projects\auris`.

## Быстрый запуск

Нужны Node.js, npm, Rust stable MSVC, Visual Studio с C++ build tools и WebView2.
Эти компоненты доступны на текущей машине. Проверка: `npm run tauri info`.

```powershell
npm ci
npm run tauri dev
```

Эта команда запускает Windows-приложение в режиме разработки. Для работы
только над интерфейсом: `npm run dev`, затем http://localhost:1420.
Браузерное превью не содержит нативного бэкенда записи и библиотеки встреч.

```powershell
npm test
npm run build
cargo test -p auris-core --locked
cargo check -p auris --locked
```

## Дополнительные возможности

Обычный запуск не включает встроенный Whisper, диаризацию и декодер Opus.
Для них нужны CMake и LLVM/libclang; укажите `LIBCLANG_PATH` на каталог с
`libclang.dll`. Для GPU дополнительно нужен Vulkan SDK (`VULKAN_SDK`).

```powershell
npm run tauri dev -- --features whisper,diarize,opus
# При установленном Vulkan SDK:
npm run tauri dev -- --features gpu,diarize,opus
```

## Данные после переименования

Текущий идентификатор — `com.auris.app`, файлы — `auris.db` и `auris.log`,
ключи настроек — `auris.*`. Перед первым запуском закройте прежнюю версию.
Приложение копирует старые каталоги в `%APPDATA%` и `%LOCALAPPDATA%` до
создания WebView. Оригинальные файлы остаются на месте для возврата к прежней
версии. Копия содержит записи, модели и профиль WebView; для неё нужно место
на диске. Уже существующий каталог Auris не перезаписывается и не объединяется
со старым. Ошибка копирования останавливает запуск, не создавая пустую библиотеку.

Настройки, тема, подписи и параметры встреч копируются в новые ключи при
запуске интерфейса. Уже заданные настройки Auris имеют приоритет.
Переименование идентификатора может оставить прежнюю установку отдельной
записью в списке приложений Windows. Удаляйте её только после проверки переноса.

## Git

`origin` указывает на новый адрес GitHub. Изменения оформляются в отдельной
ветке через PR в `main`. Подписанный установщик выпускается отдельным релизом
по инструкции `docs/RELEASE.md`.
