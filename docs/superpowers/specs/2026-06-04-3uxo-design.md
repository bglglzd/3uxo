# 3uxo («третье ухо») — дизайн v1

> Десктоп-приложение, которое записывает твои созвоны в любом приложении,
> локально расшифровывает их и превращает в организованную базу встреч с
> ИИ-выжимками и чатом по расшифровке.

## Контекст и решения

| Вопрос | Решение |
|---|---|
| Кто пишет код | Полностью ассистент (от 0 до 100), под руководством пользователя |
| Запуск записи в v1 | Вручную: кнопка + глобальная горячая клавиша (без автоопределения) |
| Первая ОС | Windows (Mac — позже) |
| Транскрибация | Локально, Whisper (`whisper-rs`) — приватно и бесплатно |
| ИИ | OpenAI-совместимый клиент: свой base URL + свой ключ |
| Метаданные «с кем/о чём» | ИИ предлагает, пользователь правит |
| Технология | Tauri (ядро на Rust + веб-интерфейс на React) |

## Что это

Приложение для Windows (затем Mac), которое по нажатию кнопки/горячей клавиши
записывает текущий созвон в **любом** приложении (Telegram, Discord, Google Meet,
Element/Matrix, браузеры — что угодно) двумя раздельными дорожками: твой голос и
голос собеседника. После остановки локально расшифровывает речь и складывает
результат в удобную библиотеку встреч с ИИ-выжимками и чатом по расшифровке.

Всё хранится локально на компьютере. Наружу уходят только запросы к ИИ — по ключу
и эндпоинту, которые задаёт пользователь.

## Архитектура

Tauri-приложение:

- **Ядро на Rust** — захват звука, запись на диск, запуск Whisper, файлы и БД.
- **Интерфейс на вебе (React)** — библиотека встреч, плеер, расшифровка, чат, настройки.
- **Связь** — команды Tauri (frontend вызывает Rust-функции).

## Компоненты

Каждый компонент — изолированный модуль с понятным интерфейсом, тестируемый отдельно.

### 1. Audio Capture (Rust)
- WASAPI **loopback** — голос собеседника (системный звук, всё, что играет в колонках).
- **Микрофон** — твой голос.
- Две **отдельные дорожки**, пишутся на диск **инкрементально** (краш не теряет запись).
- Формат: WAV (PCM) при записи; финализация по остановке.
- Зависит от: системных аудио-API Windows.

### 2. Recording Controller
- Старт/стоп: кнопка в UI + глобальная горячая клавиша.
- Значок в трее, индикатор «идёт запись», таймер длительности.
- Зависит от: Audio Capture, Storage.

### 3. Storage
- Папка на каждую встречу: аудиодорожки + `meeting.json` (метаданные, расшифровка, выжимка).
- **SQLite** — быстрый индекс для списка/поиска (id, дата, длительность, заголовок, участники, тема).
- Папка хранения настраивается.
- Зависит от: файловой системы.

### 4. Transcription (Whisper локально)
- `whisper-rs` (биндинги whisper.cpp).
- Расшифровывает **обе дорожки** и склеивает в единую хронологическую ленту реплик
  с метками **«Я» / «Собеседник»** — разделение говорящих получается бесплатно из
  двух раздельных дорожек, без сложной диаризации.
- Модель Whisper скачивается при первом запуске (выбор размера в настройках).
- Запускается автоматически после остановки записи.
- Зависит от: Storage (читает аудио, пишет расшифровку).

### 5. AI-слой
- OpenAI-совместимый HTTP-клиент: настраиваемые **base URL** и **API-ключ**
  (подходит OpenAI, OpenRouter, локальная Ollama и т.п.).
- Функции:
  - (а) предложение заголовка, участников и темы по расшифровке;
  - (б) выжимка встречи;
  - (в) чат-вопросы по расшифровке.
- Зависит от: Storage (читает расшифровку), сети.

### 6. UI (React)
- **Список встреч**: дата, с кем, тема, длительность; поиск.
- **Карточка встречи**: аудиоплеер + расшифровка (синхронизированы по времени);
  выжимка (редактируемая); чат по встрече.
- **Настройки**: горячая клавиша, модель Whisper, AI base URL/ключ, папка хранения.
- Зависит от: команд Tauri к ядру.

## Поток данных

```
Горячая клавиша/кнопка
  → Audio Capture пишет 2 дорожки на диск (инкрементально)
  → Стоп → файлы финализируются
  → Whisper расшифровывает обе дорожки → единая лента «Я»/«Собеседник»
  → AI предлагает заголовок/участников/тему + выжимку (пользователь правит)
  → запись индексируется в SQLite
  → появляется в списке встреч
```

## Обработка ошибок

- Нет аудиоустройства / недоступен loopback → понятное предупреждение, запись не стартует.
- Модель Whisper не скачана → предложить скачать, не падать.
- Нет ИИ-ключа / эндпоинт недоступен → шаг ИИ пропускается, метаданные можно заполнить вручную.
- Запись пишется на диск постепенно → краш приложения сохраняет уже записанное аудио.
- Ошибка расшифровки → встреча сохраняется как «есть аудио, нет расшифровки», можно перезапустить.

## Тестирование

- **Rust**: юнит-тесты записи/нарезки аудио и финализации файлов; прогон расшифровки
  на маленьком тестовом WAV; AI-клиент против мок-HTTP-сервера; слой Storage/SQLite.
- **Frontend**: тесты компонентов списка встреч и карточки встречи; синхронизация
  плеера и расшифровки.
