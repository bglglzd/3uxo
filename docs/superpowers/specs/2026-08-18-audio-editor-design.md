# Аудиоредактор Auris — спека (v0.7.0)

Отдельный интерфейс правки записанного аудио: видно громкость на таймлайне,
можно выделить фрагмент, вырезать его (или наоборот — оставить только его),
послушать результат до сохранения и применить правку к файлам встречи.

Дата: 2026-08-18. Ветка: `feat/audio-editor`.

---

## 1. Задача (со слов пользователя)

> «отдельная функция, переключение в отдельный интерфейс редактирования
> аудиозаписи, чтобы можно было вырезать куски; на таймлайне должно быть видно,
> где какая громкость, чтобы понятно было обрезать/вырезать/сохранить»

Из этого следуют требования:

| # | Требование | Как решается |
|---|---|---|
| R1 | Отдельный интерфейс, переключение из встречи | кнопка «✂ Редактор аудио» в карточке плеера → полноэкранный режим `AudioEditor` вместо тела `MeetingView`, кнопка «← К встрече» назад |
| R2 | На таймлайне видно громкость | карта громкости из бэкенда: пик + RMS по «корзинам»; отрисовка зеркальной волной (RMS — тело, пик — ореол) |
| R3 | Вырезать куски | drag-выделение на волне → «✂ Вырезать»; список вырезов накапливается, каждый можно снять |
| R4 | Обрезать | «⇥ Оставить только это» = вырезать всё вне выделения (обрезка началом/концом — тот же примитив) |
| R5 | Сохранить | «✓ Применить» перезаписывает дорожки встречи, обновляет длительность и сдвигает расшифровку |
| R6 | Понятность | зум ×1…×16, точный ввод границ (мм:сс.д), предпрослушивание «как будет» (пропуск вырезов), счётчик «было → станет» |

Дополнительно (принцип проекта «ничего не убираем — только добавляем»):

- **Оригинал не теряется.** Первая правка встречи копирует дорожки в
  `*.orig.wav` и расшифровку в `transcript.orig.json`; кнопка «↺ Вернуть
  оригинал» возвращает всё как было.
- Существующие функции (плеер, скачивание дорожек, расшифровка, ИИ, экспорт)
  не меняются.

---

## 2. Модель правки

**Деструктивное применение + однократный бэкап оригинала.**

Редактор всегда работает по *текущим* файлам встречи, поэтому таймлайн, вырезы
и расшифровка живут в одной системе координат — не нужно ничего пересчитывать
между «оригиналом» и «текущим». Повторные правки просто накапливаются; потери
качества нет, т.к. это PCM i16 → PCM i16 без перекодирования.

```
<app_data>/meetings/<id>/
  mic.wav / system.wav      записанная встреча (две дорожки)  ← правятся вместе
  audio.wav                 импортированная встреча (одна дорожка)
  mic.orig.wav / system.orig.wav / audio.orig.wav   бэкап ДО первой правки
  transcript.json           расшифровка (сдвигается вместе с аудио)
  transcript.orig.json      бэкап расшифровки ДО первой правки
```

Инварианты:

1. У записанной встречи обе дорожки правятся **одним и тем же** набором вырезов
   — иначе «Я» и «Собеседник» разъедутся во времени.
2. `*.orig.wav` создаётся **только если ещё не существует** — бэкап всегда
   указывает на исходную запись, а не на предыдущую правку.
3. `duration_secs` встречи в БД обновляется по фактической длине после правки.
4. Расшифровка (если есть) пересчитывается тем же набором вырезов:
   реплика целиком внутри выреза — удаляется; частично — время подрезается,
   текст сохраняется; последующие — сдвигаются влево.

## 3. Бэкенд

### `core/src/edit.rs` (новый модуль, без фич, кросс-платформенный)

```rust
pub struct Range { pub start_secs: f64, pub end_secs: f64 }

pub struct Waveform {
    pub peaks: Vec<u16>,   // пик амплитуды в корзине, 0..1000
    pub rms:   Vec<u16>,   // средняя громкость в корзине, 0..1000
    pub duration_secs: f64,
    pub sample_rate: u32,
}

/// Карта громкости WAV-дорожки для таймлайна. Читает файл потоково
/// (2-часовая запись = 230 МБ — в память не поднимаем).
pub fn waveform(path: &Path, buckets: usize) -> AppResult<Waveform>;

/// Склеивает/сортирует интервалы, отбрасывает пустые.
pub fn merge_ranges(ranges: &[Range]) -> Vec<Range>;

/// Время `t` исходной дорожки → время после вырезов (монотонно, точка внутри
/// выреза садится на его начало).
pub fn map_time(t: f64, merged: &[Range]) -> f64;

/// Пишет `dst` = `src` без интервалов `cuts` (PCM i16 без перекодирования).
/// Возвращает длительность результата.
pub fn apply_cuts(src: &Path, dst: &Path, cuts: &[Range]) -> AppResult<f64>;

/// Пересчитывает времена расшифровки под вырезы (см. инвариант 4).
pub fn remap_transcript(t: &Transcript, cuts: &[Range]) -> Transcript;
```

Шкала громкости 0..1000 — та же, что у `recorder::TrackLevels`/
`recording_levels` (живые тайлы записи), чтобы во всём приложении громкость
измерялась одинаково.

### `core/src/service.rs`

```rust
pub struct AudioEditState { pub tracks: Vec<String>, pub has_original: bool }

pub fn audio_edit_state(data_root, id) -> AppResult<AudioEditState>;
/// Тяжёлая файловая часть без БД (для spawn_blocking): бэкап → вырезы по всем
/// дорожкам → пересчёт transcript.json. Возвращает новую длительность (сек).
pub fn apply_audio_edit_files(data_root, id, cuts: &[Range]) -> AppResult<u64>;
/// Возврат к оригиналу из бэкапа. Возвращает длительность оригинала.
pub fn revert_audio_edit_files(data_root, id) -> AppResult<u64>;
```

`storage::Repo::update_duration(id, secs)` — новый метод (по образцу
`update_status`).

### Команды Tauri (`src-tauri/src/commands.rs` + регистрация в `lib.rs`)

| Команда | Аргументы | Результат |
|---|---|---|
| `waveform` | `id`, `trackFile`, `buckets` | `Waveform` |
| `audio_edit_state` | `id` | `AudioEditState` |
| `apply_audio_edit` | `id`, `cuts: Range[]` | обновлённый `Meeting` |
| `revert_audio_edit` | `id` | обновлённый `Meeting` |

`waveform` и обе правки — `async` + `spawn_blocking` (файловый ввод-вывод не
должен подвешивать окно), запись в БД — уже в async-потоке, как в
`import_recording`. Путь к дорожке валидируется существующим
`service::track_path` (защита от path traversal + белый список имён).

## 4. Фронтенд

- `src/audioedit.ts` — чистая логика (юнит-тесты): `mergeCuts`, `cutsTotal`,
  `keptDuration`, `invertCuts`, `skipTarget`, `removeCutAt`, `downsample`,
  `clockPrecise`, `parseClock`, `toRanges`.
- `src/components/WaveTimeline.tsx` — одна дорожка: волна (SVG `<path>`,
  RMS + пик), слой вырезов, выделение, плейхед, drag/клик-сик.
- `src/components/AudioEditor.tsx` — экран редактора: тулбар, дорожки, футер.
- `src/components/MeetingView.tsx` — кнопка «✂ Редактор аудио» и переключение
  режима; после правки перезагружает аудио (cache-buster в asset-URL),
  расшифровку и метаданные встречи.
- `src/App.css` — секция `.audio-editor` на токенах Auris: вырезы — цветом
  записи (`--rec`), выделение — акцентом (`--accent`), волна «Я» — `--spk-0`,
  «Собеседник» — `--spk-1`.

### Взаимодействие

| Действие | Результат |
|---|---|
| протянуть по волне | выделение (подсветка + читаемые границы) |
| клик по волне | перенести плейхед (сик) |
| «✂ Вырезать» / `Delete` | выделение → в список вырезов |
| «⇥ Оставить только это» | вырезы = всё вне выделения |
| «✕» на вырезе | снять этот вырез |
| «↶ / ↷» | undo/redo списка вырезов |
| «▶/⏸» / `Space` | воспроизведение (все дорожки синхронно) |
| тумблер «Пропускать вырезы» | предпрослушивание результата |
| зум ×1…×16 | плотность волны; дорожки скроллятся синхронно |
| «✓ Применить» | подтверждение → запись файлов, обновление встречи |
| «↺ Вернуть оригинал» | подтверждение → откат к бэкапу |

Редактор недоступен, пока идёт расшифровка этой встречи (правка файлов из-под
whisper) — кнопка выключена с подсказкой.
